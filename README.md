# Bestiario

App web para registrar personajes de fantasía.

## Firebase

Los personajes (nombre, historia, puntajes, tipo, clan e imagen en base64) se guardan en Firestore, colección `characters`.

Antes de usar la app, reemplaza en `index.html` los valores de `firebaseConfig`:

- `apiKey`
- `authDomain`
- `projectId`
- `storageBucket`
- `messagingSenderId`
- `appId`
